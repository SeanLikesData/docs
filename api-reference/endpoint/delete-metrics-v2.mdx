<EndpointBar method="POST" path="/v2/delete-metrics" />

Deletes one or many custom metrics.

<Note>`custom_metric_ids` takes one metric ID or a list of IDs. Each ID must exist and belong to your organization. The metrics move to Recently Deleted.</Note>

```json
{ "custom_metric_ids": "3c90c3cc-0d44-4b50-8888-8dd25736052a" }
```
