<Warning>
[JSON will be deprecated](/bluejay-as-code/overview#move-from-json-to-yaml) on November 20th, 2026.
</Warning>

Export a bundle of your setup with these lists:

- `agents`
- `simulations`
- `personas`
- `digital_humans`
- `custom_metrics`

Each item has a `bluejay_as_code_id`.

Supported values for `root_type` include:

- `simulation`
- `agent`
- `digital-human`
- `custom-metric`

`root_id` is the Bluejay ID or the `bluejay_as_code_id` of the root.

Commit the `bluejay_as_code_id` values to your config. Do not create new values for each push.

The response is YAML. To get JSON until it is deprecated, add the query parameter `format=json` or send the header `Accept: application/json`.

```bash
curl "https://api.getbluejay.ai/v1/bluejay-as-code/simulation/$SIM_ID" \
  --header "X-API-Key: $BLUEJAY_API_KEY" \
  --output simulation.yaml
```
