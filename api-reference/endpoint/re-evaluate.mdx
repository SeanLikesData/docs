<EndpointBar method="POST" path="/v1/re-evaluate/{conversation_id}" />

Creates a new evaluation for a conversation.

The JSON body is optional. Send `{"version": 3}` to score against agent version 3. Omit the body, or send `{}`, to keep the version stored on the conversation. An unknown version returns 400.
