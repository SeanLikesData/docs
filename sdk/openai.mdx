`BluejayClient(tracing=True)` traces the OpenAI SDK. No extra package. Chat completions and responses are covered: `create`, `parse`, and `stream`, including Azure OpenAI and OpenAI-compatible clients.

```python
from bluejay import BluejayClient

client = BluejayClient(tracing=True)

# this call is a span, with the model, prompt, reply, tool calls, tokens, and finish reason
reply = openai_client.chat.completions.create(model="gpt-4o-mini", messages=messages)
```

When the call runs inside a [session](/sdk/observability#trace-chat-or-sms), the span joins that call.
