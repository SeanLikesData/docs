`init_tracing()` traces the OpenAI SDK. No extra package. Chat completions and responses are covered: `create`, `parse`, and `stream`, including Azure OpenAI and OpenAI-compatible clients.

```python
client.init_tracing()

# this call is a span, with the model, prompt, reply, tool calls, tokens, and finish reason
reply = openai_client.chat.completions.create(model="gpt-4o-mini", messages=messages)
```

Inside a [session](/sdk/overview#write-each-utterance), the span joins that call.
