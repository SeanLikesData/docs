Use the Bluejay SDK to observe production conversations, run simulations, and call the Bluejay API. The SDK is available for Python. TypeScript support is coming.

## Install and authenticate

The Python examples require `bluejay-sdk` 0.4.0 or later and Python 3.10 or later. The Pipecat extra requires Python 3.11 or later.

<CodeGroup>

```bash Python
pip install "bluejay-sdk>=0.4.0"
```

```typescript TypeScript
// The TypeScript SDK is coming.
```

</CodeGroup>

Create a key in [API Keys](https://app.getbluejay.ai/settings/api-keys) and set it in the environment where the SDK runs.

```bash
export BLUEJAY_API_KEY="your-api-key"
```

## Make your first request

<CodeGroup>

```python Python
from bluejay import BluejayClient

client = BluejayClient()
for agent in client.agents.list():
    print(agent.id)
```

```typescript TypeScript
// The TypeScript SDK is coming.
```

</CodeGroup>

Use `BluejayClient()` to call the API. Use `BluejayClient(tracing=True)` once at startup in a process that sends agent telemetry. Both clients read the same API key. Add the [observability integration](/sdk/observability) for your agent to capture conversations.

In asyncio applications, use `AsyncBluejayClient` and await HTTP methods such as `client.agents.list()` and `client.simulations.run(...)`. Methods that write spans, such as `client.turn()`, are synchronous.

## API reference

The SDK groups API methods by resource. For example, use `client.agents.list()` for agents, `client.simulations.run(...)` to queue a test, and `client.simulation_results.list(...)` to read a run. The [API reference](/api-reference/endpoint/get-all-agents) describes request fields and response models.
